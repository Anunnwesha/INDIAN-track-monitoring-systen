# 🚆 Indigenous Smart Track Monitoring System for Indian Railways

### A Low-Cost, GPS-Independent Integrated Track Monitoring System (ITMS)

## 📌 Project Overview

The Indigenous Smart Track Monitoring System aims to improve railway safety through automated, contactless track monitoring. It offers a cost-effective alternative to expensive imported Track Recording Cars (TRCs) and manual inspections.

Developed as part of **Smart India Hackathon (SIH) 2025**, this project focuses on track condition monitoring, fault detection, obstacle detection, and railway component traceability.

## 🎯 Key Features

* **Vibration Monitoring:** Uses the MPU6050 sensor to collect vibration and ride-quality data.
* **Track Identification:** Explores laser-based markers and RFID/UHF tags for sleeper identification.
* **Obstacle Detection:** Uses ESP32-CAM for detecting obstacles on railway tracks.
* **Fault Detection:** Aims to identify abnormal vibrations and potential track faults.
* **GPS-Independent Monitoring:** Enables track component mapping without relying on GPS.
* **Cost-Effective Design:** Focuses on an affordable, modular, and scalable solution.

## 🛠️ Hardware Components

* ESP32-CAM
* MPU6050 Accelerometer and Gyroscope
* RFID/UHF tags or laser-based markers
* Obstacle detection module
* Prototype train model

## ⚙️ Working Principle

1. Sensors collect vibration and ride-quality data.
2. The system processes sensor readings to identify abnormal conditions.
3. Track identification methods help map data to individual sleepers and fittings.
4. Obstacle detection supports identifying potential hazards.
5. The collected data can be stored and analysed for maintenance and safety monitoring.

## 🌟 Expected Benefits

* Improved railway track safety
* Early identification of potential faults
* Reduced dependence on manual inspections
* Better traceability of track components
* Lower monitoring and maintenance costs
* Support for preventive railway maintenance
